# 赛前简报

`python -m ptcg.brief` 生成，每周一 `collect` 更新数据后自动重算。

- `<窗口>.md`：首页，会遇到谁、带哪套、卡表怎么微调。
- `<窗口>/<卡组>.md`：推荐卡组的对局速查，每个对手 3 到 5 条要点，加上这个对局里差值大的卡。
- 人工维护的两处：`picks.yaml`（推荐分档、理由、适合谁；最新数字不再支持分档时，首页会提示）和
  `points/<卡组>.yaml`（从 `data/matchups/` 长版手册提炼的要点；复述台账判断的要点带 `judgment` 编号，速查里显示它的当前信心）。
  改了长版手册里的打法，要同步改对应的要点。
