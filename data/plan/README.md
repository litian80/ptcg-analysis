# 夺冠方案

`python -m ptcg.plan [--region EU|NA|LA|OC]` 生成 `<日期>.md`，每周一 `collect` 更新数据后自动出一份新的（日期是数据里最后一场比赛加 7 天）。
目标是帮进阶选手进前 8、夺冠：

1. 前排会遇到谁：`ptcg.forecast` 预测全场份额，再乘各卡组过去进前 32 的比例。
2. 带哪套：进前 32 的历史比例和对预计环境的期望胜率加权打分。每场比赛都只用它之前的数据回测，结果写在 `data/forecast/forecast.json`。
3. 单卡调整：`ptcg.tuning`，只比较 Day 2 选手、只算 Day 2 对局，按选手聚类算误差，多重比较校正后 q < 0.2 才给建议；Day 2 卡表少于 40 份的卡组不给建议。
4. 对前排卡组的要点：取自 `data/brief/points/`。

人工维护：`notes.yaml`，写每条单卡建议为什么成立（卡牌原文或手册），没写的会标"原因还没核实"。
旧的方案留着，以后可以拿实际比赛结果检验当时的建议。
